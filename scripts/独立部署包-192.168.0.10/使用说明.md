# pi 采集上传脚本 独立部署包（服务器：192.168.0.10）

> 适用场景：在其他同事的 PC 上部署 pi 运行数据采集 + 自动上传。
> 上传目标默认已改为 **http://192.168.0.10:3002**，无需再配置环境变量。
> 原工程文件未做任何修改，本包为独立副本。

---

## 一、包内文件

| 文件 | 作用 | 部署位置（别人电脑上） |
| --- | --- | --- |
| `pi_extension_capture.ts` | pi 扩展，采集会话/LLM/工具事件，落盘 JSONL 并触发上传 | `~/.pi/agent/extensions/`（全局）或项目 `.pi/agent/extensions/` |
| `upload.cjs` | 上传脚本，读取 spool 目录中的 JSONL 并 POST 到服务器 | `~/.linkAI-capture/upload.cjs`（固定位置） |

- 两个脚本均只用 Node 内置模块，**无需 npm install**，pi 自带的 Node 运行时即可。
- Windows 下 `~` 即 `C:\Users\<用户名>`。

---

## 二、部署步骤（别人电脑上）

1. **安装捕获脚本**
   把 `pi_extension_capture.ts` 复制到 pi 的扩展目录：
   ```
   C:\Users\<用户名>\.pi\agent\extensions\pi_extension_capture.ts
   ```
   （全局安装对所有项目生效；只想对某个项目生效则放到该项目的 `.pi\agent\extensions\` 下。）

2. **安装上传脚本**
   把 `upload.cjs` 复制到 spool 固定位置：
   ```
   C:\Users\<用户名>\.linkAI-capture\upload.cjs
   ```
   目录不存在就手动创建。

3. **确认网络可达**
   在命令行执行：
   ```
   curl http://192.168.0.10:3002
   ```
   能连通即可（返回什么都行，只要不是连接超时/拒绝）。

4. **启动 pi 正常使用**
   无需任何环境变量。首次会话数据会自动落盘并触发上传。

---

## 三、数据落在哪里 / 传到哪里

- **本地落盘**：`~/.linkAI-capture/<用户名>/<项目ID>/<日期>/pi-<sessionId>-<时间戳>.jsonl`
- **上传目标**：`http://192.168.0.10:3002`（服务端接口 `POST /api/sessions/upload`）
- **触发时机**（全自动，无需手动干预）：
  - 每轮 agent 结束（agent_end）
  - 退出/重载 pi（session_shutdown: quit/reload、SIGINT/SIGTERM/beforeExit）
  - 扩展内置每 30 秒一次全量扫描，补传之前漏传/失败的文件
- 本地保存与上传**完全解耦**：上传失败不影响本地数据，下次扫描会自动补传。

## 四、可选配置（环境变量，一般不用设）

| 变量 | 默认值（本包已改） | 说明 |
| --- | --- | --- |
| `PI_CAPTURE_BACKEND_URL` | `http://192.168.0.10:3002` | 上传服务器地址，如换服务器才需要设 |
| `PI_CAPTURE_UPLOAD_SCRIPT` | `~/.linkAI-capture/upload.cjs` | 上传脚本路径，只在不想放默认位置时设 |
| `PI_CAPTURE_SPOOL_DIR` | `~/.linkAI-capture` | 本地数据目录 |
| `PI_CAPTURE_USER` | 当前登录用户名 | 上报的 userId |
| `PI_CAPTURE_MAX_STRING` / `PI_CAPTURE_MAX_TOOL_IO` | 4000 / 4000 | 单字段/工具输入输出的截断长度 |

## 五、排查问题

日志文件：`~/.linkAI-capture/logs/pi_plugin.log`

| 日志关键字 | 含义 |
| --- | --- |
| `extension.init` | 扩展已加载（没有这行 = 扩展没被 pi 加载，检查目录位置） |
| `upload.trigger` / `upload.scanAll` | 上传已触发 |
| `upload.spawn.error` | 找不到上传脚本 → 检查 `~/.linkAI-capture/upload.cjs` 是否存在 |
| `writer.rotated` | 数据文件已创建，本地采集正常 |

上传脚本自身日志：`~/.linkAI-capture/upload.log`（含 `scanall.done uploaded=N`）。

---

## 六、服务端前提

- `192.168.0.10` 上须运行本工程（Next.js），监听 **3002** 端口。
- 部署包内的地址为局域网地址，仅限同一局域网内的机器使用；跨网段需改用可达的 IP/域名（用 `PI_CAPTURE_BACKEND_URL` 覆盖即可，无需改文件）。
